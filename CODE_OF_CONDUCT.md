# Code of Conduct

## Scope

This policy applies to project spaces, including repository issues, pull
requests, discussions, code review, and direct project communication.

## Expected behavior

Participants are expected to be respectful, patient, and constructive. Give
useful rationale, assume good intent when interpreting questions, and keep
feedback focused on code, docs, process, and behavior rather than individuals.

## Unacceptable behavior

- Harassment, discrimination, personal attacks, or threats.
- Publishing another person's private information without consent.
- Deliberate misinformation, bad-faith disruption, or spam.
- Sexualized, abusive, hateful, or demeaning language.
- Repeated unwanted contact after a request to stop.

## Reporting

Use GitHub's repository reporting controls for abusive content, or contact the
repository owner through their GitHub profile for private conduct reports. Do
not use public issues for sensitive conduct reports.

Reports will be handled with discretion. The maintainers may warn, mute,
temporarily restrict, or permanently remove a participant who violates this
policy.
