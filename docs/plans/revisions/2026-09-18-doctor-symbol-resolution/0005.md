# Goal

Doctor plan-symbol warnings must be trustworthy. The Python parser currently misses
decorated functions and classes such as Typer commands and dataclasses, while
doctor reports unresolved references for every historical plan. This plan makes
decorated Python definitions visible to the index and scopes unresolved-symbol
warnings to plans that are still active.

# Non-goals

- Do not build semantic search or enrichment.
- Do not index every Python module-level variable or import re-export.
- Do not rewrite or delete historical plan evidence.
- Do not change `plan stale` output shape or lifecycle behavior.
