# Engineering requirements

- CLI output must not raise UnicodeEncodeError on Windows with GBK codepage; wrap or configure the rich console to handle encoding errors gracefully.
- _slugify() must strip leading date patterns (YYYY-MM-DD-) from slugs so the generated plan ID does not contain the date twice.
- CI matrix must include macOS-latest with at least Python 3.13 to cover the Apple Silicon platform.
- Go parser must extract functions, methods, structs, interfaces, imports, and function calls using tree-sitter-go.
- The parse_file() dispatch must be extensible: language-specific symbol extraction should be selected via a dispatch mechanism rather than an if/else on "python" vs "everything else is JS".
