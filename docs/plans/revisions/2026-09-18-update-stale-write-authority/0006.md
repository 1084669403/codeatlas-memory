# Goal

Make update-time stale revalidation explicit and safe: when recorded batch
inputs no longer match current code, `update` can mark the affected passed batch
stale through the canonical plan writer, but only when plan-state writing is
allowed.

# Non-goals

Do not rewrite gate evidence, change plan goals or scope, reopen a `done` plan
automatically, bypass semantic reapproval, or make indexing depend on plan
mutation.
