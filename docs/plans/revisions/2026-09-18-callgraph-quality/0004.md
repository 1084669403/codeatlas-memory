- `_resolve_imports()` must correctly resolve `from .module import X` by
  computing the current file's directory and appending the module path.
- `from . import X` must resolve to the current package's `__init__.py`.
- `_module_prefix()` must handle `.go` extension (strip `.go`, use forward
  slashes, and derive a Go-style package prefix).
- `resolve_callee()` for Go files must try `pkg.Function` where `pkg` is
  resolved via the import map.
- The existing Python absolute import path must not regress.
- All changes must be backward-compatible with the existing 244+ tests.
